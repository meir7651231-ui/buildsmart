# 🎛️ CATALOG-CONFIG — הקטלוג-המגדיר (מסך צלילה + כרטיס-פרמטרי פר-מוצר)

> **החזון (נעול, מהמוקאפ `dive-bs2b`):** צולל בקטלוג → נוגע במוצר → נפתח **כרטיס-הגדרה** עם **תמונה במרכז** ו**גלגלים שמשתנים לפי המוצר**. → לסל / בנה-קו.
> **הלב:** הכרטיס **גנרי ודאטה-מונחה** — כל מוצר "מצהיר" אילו גלגלים הוא צריך (תכונות + ערכים) + תמונה-לכל-שילוב. **אין קוד פר-מוצר.**
> **מקור-UI:** קובץ-העיצוב `Catalog.dc.html` (האינטראקציה: אקורדיון-inline · גלגל עם פס-בחירה · כרטיס-מרכז) — מולבש BuildSmart (עגול · כתום · אימוגי).
> **מקורקע בקוד החי:** משפחות=`categoryHe`/`catalog_tree` · תכונות=`AttributeDef`/`AttrKind`/`VariantFamily` · נגזרות-מנוע=`familyOf`/`odOf`/`kDepth` · תמונות=`imageAsset`/`imageFiles` · סל=`smartCart.add` · בנה-קו=`buildInstallation`.
> **בלי 3D** — רק תמונות.

---

## המסך (נעול · 4 רבדים)
1. **צינורות מים** — כותרת ראשית.
2. **משפחות = מחלקות** (אביזרי קצה 143 · PPR 774 · ברזים 20 · מחלקים 11 · אטמים 17…) — **פתוחות** (רַיל גלוי, כמו העיצוב).
3. **אריחי-מוצר** ברַיל — אימוגי + שם + תכונות.
4. **כרטיס-הגדרה** (נפתח בנגיעה, inline): **תמונה במרכז** · **גלגלים פר-תכונה** · לסל/בנה-קו.

---

## 🫀 הלב: המודל הדאטה-מונחה (`ProductConfigSchema`)
כל מוצר מצהיר סכמה; הכרטיס מרנדר אותה גנרית.
```
ProductConfigSchema {
  sku · nameHe · familyId(מחלקה) · emoji
  attributes: [                     // ← הגלגלים, משתנים לפי מוצר
    { key · labelHe · kind(number|option|color) · values[] · default }
  ]
  imageFor(selection) → asset       // ← תמונה לכל שילוב (בלי 3D)
  priceFor(selection) → ₪
}
```
**דוגמאות-זהב (verbatim):**
- **ברך:** `[{זווית: 15·30·45·90}, {קוטר: 20·25·32·40·50}, {אורך: קצר·בינוני·ארוך}]` + כמות.
- **מחלק:** `[{יציאות: 1·2·3·4}, {צבע: swatches}, {קוטר: 20·25·32}]` + כמות.
- **מצמד:** `[{קוטר: 20·25·32·40·50}]` + כמות (גלגל יחיד).
- **מצרה:** `[{קוטר-גדול}, {קוטר-קטן}]` + כמות.

## הפאזות (לעוסות · מקורקעות)

### פאזה 0 · מודל-התכונות *(הלב · הכי חשוב)*
- **0.1** הגדר `ProductConfigSchema` + `AttrKind`(number/option/color) — **בנה על** `AttributeDef`/`VariantFamily` הקיימים (`variant_families.dart`), לא מאפס.
- **0.2 · גזירה-אוטומטית (מקטין הזנה-ידנית):** ל-fittings, `familyOf(p)` → אילו תכונות (ברך→זווית+קוטר+אורך · מצמד→קוטר · מצרה→2-קטרים · ברז→קוטר · מחלק→יציאות) · `odOf`/`kDepth` → ערכי-הקוטר. **רוב הסכמה נגזרת מהמנוע.**
- **0.3 · תכונות-קטלוג** (לא-נגזרות): צבע · יציאות · תבריג → מ-`dims`/`nameHe` או שדה-חדש.
- **0.4 · golden:** סכמת ברך + מחלק verbatim → `config_schema_test`.
- **שומר:** אין תכונה שאין לה ערכים · `null`-fallback (מוצר בלי סכמה → כרטיס-בסיס עם קוטר בלבד).

### פאזה A · שכבת-הצלילה (browse) — *כמו העיצוב, פתוח*
- **A.1** section→משפחות(מחלקות, **פתוחות**)→רַיל-אריחים. מ-`categoryHe`/`catalog_tree`.
- **A.2** אימוגי פר-משפחה+מוצר (דאטה). פינות-עגולות · כתום · לבן (BuildSmart).
- **A.3** פורט האינטראקציה מ-`Catalog.dc.html` (אקורדיון-inline · הרַיל נשאר · נפתח-בנגיעה) ל-Flutter.

### פאזה B · הכרטיס-הגנרי
- **B.1** widget יחיד שמקבל `ProductConfigSchema` → מרנדר **N גלגלים** (פר-תכונה) + **תמונה-מרכז**. אפס-hardcode.
- **B.2** נפתח inline מתחת לאריח-שנגע (אקורדיון), השאר נשאר.

### פאזה C · הגלגלים
- **C.1** `WheelPicker` — גלילה/נגיעה · פס-בחירה · דחיית-neighbors · מספר-משתנה. פורט-מכניקה מ-`Catalog.dc.html` (translateY · band).
- **C.2** גלגל-צבע (swatches) · גלגל-מספר · גלגל-אופציות — לפי `kind`.

### פאזה D · התמונה (בלי 3D)
- **D.1** `imageFor(selection)` → asset. מתחלף בזמן-בחירה. **מקורקע:** `imageAsset`/`imageFiles`/`specImageFiles` הקיימים בקטלוג.
- **D.2** fallback: אין תמונה-פר-שילוב → תמונת-מוצר-בסיס → אימוגי. אף פעם לא ריק.

### פאזה E · סל + בנה-קו
- **E.1 · הוסף-לסל** = `SmartCartLine(sku, selection, qty)` → `smartCart.add`. הקונפיג נשמר בשורה.
- **E.2 · בנה-קו** = פותח את גרף-החיבורים (`buildInstallation`/`findShortestPath`) — endgame, מגודר בנפרד.

### פאזה F · אוכלוסיית-דאטה (פילוט אביזרי-קצה)
- **F.1** מלא סכמות+תמונות ל-**אביזרי קצה** (ברך·מצמד·טי·מתאם·מצרה·פקק) — רובן נגזרות (0.2), השאר ידני.
- **F.2** אז שאר המשפחות (PPR·ברזים·מחלקים·אטמים…).
- **דוח-כיסוי:** כמה מוצרים עם סכמה-מלאה / תמונה.

### פאזה G · גידור + פילוט + שילוח
- מגודר `kCatalogConfig` **default-OFF** · off-live · פילוט אביזרי-קצה → CI ירוק + visual-verify → הכללה.
- **🛑 הדלקה-חיה על הקטלוג = החלטת-בעלים מפורשת.**

## 📥 מפרט-הדאטה (מה מעלים פר-מוצר)
| שדה | מה | מקור |
|---|---|---|
| `sku · nameHe · familyId` | זיהוי + מחלקה | קטלוג קיים |
| `emoji` | אייקון-אריח | חדש (קטן) |
| `attributes[]` | הגלגלים: `{key,label,kind,values[],default}` | **נגזר** (מנוע) + ידני (צבע/יציאות) |
| `imageMap` | תמונה-לכל-שילוב | `imageAsset`/`imageFiles` קיים + השלמה |
| `priceRule` | מחיר-לכל-שילוב | `priceFor` / קטלוג |

**ברך:** attrs=[זווית·קוטר·אורך] · תמונה-פר-זווית · price(od).
**מחלק:** attrs=[יציאות·צבע·קוטר] · תמונה-פר-יציאות+צבע.

## 🛡️ שומרים
- **גנרי · דאטה-מונחה** — אפס קוד-פר-מוצר. מוצר-חדש = שורת-דאטה.
- **בלי 3D** — תמונות בלבד.
- **מגודר default-OFF** · off-live · פילוט-אביזרי-קצה-קודם · הדלקה=בעלים.
- **מקורקע:** בונים על הקטלוג/מנוע/AttributeDef הקיימים · UI מ-`Catalog.dc.html`. לא ממציאים.
- **null-fallback** בכל שכבה (אין סכמה→קוטר · אין תמונה→אימוגי).
