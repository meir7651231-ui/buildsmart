> נרשם 14/6 לבקשת המשתמש ("תרשום בצד, נחזור מאוחר יותר").
> **לא קשור להשקה** — אף פריט כאן לא חוסם העלאה לחנויות. אלה **מבדלים ל‑v2**, אחרי שהאפליקציה חיה.
> כל ה‑4 **חיים *בתוך* BuildSmart** (לא מוצרים נפרדים שהמשתמש יוצא אליהם).

## המבנה: 3 כלים + מנהל אחד (2 כובעים)
- **אין "כלי אחד לכל"** — כל צורך = התמחות נפרדת. מי שמבטיח כלי‑קסם אחד = בינוניות.
- **3 כלים מומחים** (ראה למטה).
- **המנהל = 2 כובעים:**
  1. **קופיילוט‑AI** (Claude / ChatGPT) — עוזר *לך* ליצור · לכתוב פרומפטים · לבחור. היד‑הימנית בזמן יצירה.
  2. **הצי** — משתיל את ה‑API של הכלים לתוך האפליקציה כך שזה רץ אוטומטית למשתמשים.
- במשפט: **3 כלים מומחים · אתה+קופיילוט יוצרים · הצי משתיל באפליקציה.**

## הפיצ'רים (5)

### 1. 🏢 בניין‑3D (תוכנית → בניין שמנווטים בו)
- **מה:** נותנים תוכנית‑בנייה → נוצר מבנה תלת‑מימד שמנווטים בו. "יש משימה בקומה 3 → קח אותי לשם". כמו ווייז בתוך הבניין.
- **כלים:** המרת‑תוכנית — Planner 5D / Foursite. ניווט‑בבניין (מנוע BIM) — ThatOpen / IFC.js (קוד‑פתוח) או Autodesk APS.
- **גודל:** הכי גדול/מורכב מה‑4 — כמעט מוצר בפני עצמו.

### 2. 📦 קטלוג‑3D (תמונת‑מוצר → 3D/360)
- **מה:** תמונת‑מוצר אחת + מפרט → מוצר תלת‑מימד / 360° שמסתובב בתוך הקטלוג.
- **כלים:** image‑to‑3D — **Meshy** או **Tripo** (פלט GLB → צופה‑תלת‑מימד `model-viewer` בדף‑המוצר).
- **עלות/ROI:** אגורות למוצר (~$100–$500/שנה לכל הקטלוג, מול עשרות‑אלפי $ בצילום‑360 רגיל); 360° → ~+27% המרות, פחות החזרות.
- **כנות:** מצוין לרוב המוצרים; חלקים מורכבים יצריכו בדיקה/ניקוי → לבנות עם "אשר/דחה" פר‑מוצר.

### 3. 🖼️ אייקונים — אימוג'י → תמונות יפות
- **מה:** להחליף אימוג'י בסט תמונות אחיד ויפה. **מתחילים מהחשוף‑ללקוח:** קטגוריות · מחלקות · קטלוג. (תפריטים עמוקים — אימוג'י נשאר.)
- **כלים:** יצירה — **Midjourney** (הכי אחיד) / DALL‑E / Imagen. (Canva יכול גם.)
- **איך:** ⚠️ **סגנון אחד עקבי** (סט לא‑אחיד נראה גרוע מאימוג'י נקי) · היברידי · הצי מחליף בקוד + R2/CDN + WebP + fallback לאימוג'י.
- **🟡 החלטה פתוחה:** סגנון — **צילום‑אמיתי** או **רנדר‑תלת‑מימד‑אמיתי** (האחרון אחיד/פרימיום יותר — מומלץ).

### 4. 🎨 עיצוב‑שיווקי (באנרים · מבצעים · הודעות · הדגמות)
- **א. יצירת‑אסטים (בשבילך):** **Canva** + ערכת‑מותג (כתום `#FF7A18` + Heebo) — באנרים/מבצעים/הכרזות אחידים, יש AI, מסתדר עם עברית.
- **ב. הצגה באפליקציה (הצי בונה):** **מודול‑מבצעים** — קרוסלת‑באנרים בבית · כרטיסי‑מבצע · פס‑הכרזה · ויזואלים להתראות; נשלף מ‑R2, ניתן לתזמן.
- **מעל הכל:** **מערכת‑עיצוב אחת** — שגם #3 (אייקונים) וגם #4 (באנרים) יתאימו.

### 5. 🤖 עוזר‑AI ראשי בתוך האפליקציה (E3 — LLM אמיתי במקום canned)
- **מה:** המוח החכם שחי בתוך BuildSmart (היום ב‑AI hub = canned/מזויף, מוסתר ב‑`kHideUnderConstruction`). מחברים LLM אמיתי (Claude) שעונה בעברית, ממליץ חומרים, מחשב כמויות, ובונה הזמנות.
- **מודל:** **Opus 4.8** (`claude-opus-4-8`, $5/$25 ל‑1M) למוח · Sonnet 4.6 ($3/$15) מנוף‑עלות · Haiku 4.5 ($1/$5) למשימות פשוטות.
- **ארכיטקטורה:** `אפליקציה → Firebase Function (המפתח חי כסוד, אף פעם לא באפליקציה) → Claude → חזרה`.
- **סוכן אמיתי (tool‑use):** 4 כלים — 🔎 `search_catalog` · ➕ `add_to_cart` · 🧮 `compute_quantity` · 📦 `order_status`. Claude מבקש כלי → ה‑Function מריץ מול Firestore → מחזיר → Claude עונה.
- **עלות:** אגורות לשיחה עם prompt caching (~0.1× בקריאות חוזרות) + תקרת‑טוקנים + Blaze alerts.
- **ספק מלא:** `SPEC-ai-assistant.md`. ⚠️ E3 = אחרי השקה (לא חוסם; ה‑hub מוסתר).

## למה בפארק (ולא עכשיו)
- אף פריט **לא חוסם השקה** (אפל לא דוחה אימוג'י · הקטלוג עובד · הבניין = מותרות).
- ביחד = **חודשים** של עבודה.
- לרדוף אחריהם עכשיו = **לדחות את החנויות**, כשהליבה כמעט גמורה.
- **התוכנית:** הצי מסיים השקה → חוזרים לכאן.
- **חריג אפשרי לשקול:** באצ' ראשון של **אייקוני‑קטגוריות** *לפני* השקה — משפר צילומי‑מסך בחנות ורושם‑ראשון. להחלטה.
