> **prep מראש** של כל הצעדים + הדרישות (לקח מהגאנטלט: לדעת הכל מראש). מקרא: 📱 console=אתה · 🤖 CI/אני.

## סדר-הצעדים + מה צריך לכל אחד

### 1. 🔒 הסרת Project IAM Admin (אחרי functions ✅)
- 📱 **אתה:** [IAM](https://console.cloud.google.com/iam-admin/iam?project=buildsmart-b0b78) → `firebase-adminsdk-fbsvc@...` → ✏️ → הסר **Project IAM Admin** → Save.
- **למה בטוח:** ה-bindings שהוקצו בפריסה הראשונה **נשארים קבועים**. משאירים את 5 התפקידים האחרים.
- **דרישה:** שפריסת-functions הראשונה הצליחה.

### 2. 📱 הכנת test-phone (אפשר עכשיו — לא תלוי בכלום!)
- Firebase → **Authentication** → **Sign-in method** → **Phone** → גלול ל-**Phone numbers for testing** → הוסף: מספר (למשל שלך, `+9725...`) + קוד-קבוע (למשל `123456`).
- **למה:** לבדוק התחברות **בלי לשרוף מכסת-SMS** (10/יום) ובלי תלות בקליטה. הקוד תמיד אותו דבר.

### 3. 🔀 הדלקת הדגל (לראות backend אמיתי)
- 🤖 **אני מכין:** שינוי ב-`firebase-hosting.yml` → build עם `--dart-define=USE_FIREBASE_BACKEND=true`.
- **2 דרכים (החלטה כשנגיע):**
  - **(א) preview-channel** — URL זמני עם הדגל ON · **המתאים לבדיקה** (הלייב הראשי נשאר דמו).
  - **(ב) הלייב הראשי** — buildsmart-il.com עובר ל-backend אמיתי · להשקה.
- ⚠️ **השלכה:** עם הדגל, האתר **דורש התחברות** (Rules דורשות auth). נכון — זה מוצר אמיתי.

### 4. 🌱 דאטה ראשונית
- **הכי פשוט:** התחבר → **צור הזמנה/פרויקט בתוך האפליקציה** → נשמר אוטומטית. **אין uid-migration.**
- חלופה (דמו עשיר): seed-script (הצי) — דורש מיפוי-uid, מורכב יותר.

### 5. 📱 בדיקה (ה-"וואו")
- התחבר (test-phone) → צור הזמנה → **בדוק שנשמרת** + מסתנכרנת (refresh / מכשיר שני).
- שלח הודעת-צ'אט → בדוק שמגיעה. (push = דרך functions).
