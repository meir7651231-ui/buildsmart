# _catalog — מנוע-פירוק-ידע (re-runnable)

מפרק כל מסמך ב-`knowledge/` ל**אטומים** (חזון · משימה · יכולות · הוראות · תקלות · מעקפים · החלטות-בעלים · חוזה · תלויות · גידור · אימות · שאלות-פתוחות · מקור) ומקטלג.

## הרצה-מחדש
1. `kb_engine.py knowledge` → מטא מכני (סוג · תחום · עידן · הפניות) → `REGISTRY.json`.
2. נחיל קורא-בלבד (8 סוכנים) מפרק סמנטית כל אצווה → `atoms/batch-*.json`.
3. `kb_aggregate.py` → ממזג → `CATALOG.json` + `../CATALOG-INDEX.md` (תצוגות-רוחב).

## הפלט
- `../CATALOG-INDEX.md` — הקטלוג האנושי + חתכים (כל התקלות/מעקפים/החלטות-בעלים/שאלות-פתוחות).
- `CATALOG.json` — הקטלוג המכונה (170 מסמכים · 110 מפורקים סמנטית).
