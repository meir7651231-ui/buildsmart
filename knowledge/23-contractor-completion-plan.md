# השלמת פרסונת הקבלן ב-Flutter (האפליקציה הסופית) — חיווט הכפתורים הקיימים

> **עיקרון-על (תיקון הבעלים):**
> 1. **`app_flutter/` (Flutter) = האפליקציה הסופית.** לא Preact.
> 2. **אין כפתורים חדשים.** כל כפתורי-הקבלן **כבר קיימים** ב-Flutter (עצי-ה-dial מלאים, verbatim מאב-הטיפוס).
> 3. **המשימה = לחווט כל כפתור קיים** להתנהגות-האמת — היום רובם מציגים toast `'בבנייה'`.
> 4. **מקור-ההתנהגות** לכל כפתור: דוחות 01–17 + `index.html` (verbatim).
>
> שעות = עבודה ממוקדת בעזרת AI ("יום" ≈ 6ש). 🔑 ליבה · 🎨 תפאורה · 🔌 דורש-backend.

## 📌 סיכום — חיווט הקבלן ב-Flutter

| | |
|---|---|
| **עיקרון** | אין כפתורים חדשים — מחליפים toast בהתנהגות |
| **ליבה 🔑** (עץ-חכם→סל · checkout · אתר+תקציב · מלאי · חשבון-R9) | **~10–12 ימים** |
| **דורש שכבה-0 🔌** (הגשת-הזמנה · מעקב · סטטים-אמת) | **~3 ימים** |
| **תפאורה 🎨** (AI-9 · משימות-אתר-10 · פיננסים-10 · supply-chain-6 · אבטחה/שירות) | **~6–8 ימים** (אופציונלי) |
| **סה"כ הקבלן ל-100%** | **~18–22 ימים** |

### סדר מומלץ (לפי-ערך):
1. 🔑🔑 **קטלוג: עץ-חכם → סל** (~3י) — הקסם.
2. 🔑 **רכש: סל + checkout-חישוב** (~3י).
3. 🔑 **הפרויקטים: אתר + תקציב** (~2י).
4. 🔑 **בית: מלאי** + **הגדרות: חשבון-R9** (~1.5י).
5. 🔑 **פרופיל: חיבור-סטטים** (~1י).
6. 🔌 *(אחרי שכבה-0)* הגשת-הזמנה + מעקב + reorder (~3י).
7. 🎨 שאר ה-toasts → feature-sheets, לפי-זמן.

> **אחרי 1–5 (~10 ימים):** כל כפתורי-הליבה של הקבלן ב-Flutter **עובדים** (על דמו) — אפליקציה סופית מרשימה. אחרי 6 — מזמין באמת.
