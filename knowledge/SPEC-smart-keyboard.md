## 0. עיקרון‑על (תואם R2)
**אל תמלא את המסך — שים הצעות+כלים במשטח קומפקטי צמוד לקלט.** משאירים את מקשי‑המערכת (עברית/RTL/קול/נגישות בחינם) ומוסיפים שכבת‑חוכמה מעליהם. זה ה‑dial של ההקלדה: רצועה, לא חלון.

⚠️ הבחנה טכנית שמגדירה היתכנות:
- **(א) פאנל‑קלט בתוך האפליקציה** — widget שמשלים/מחליף קלט **רק בשדות BuildSmart**, קורא ישירות את הדאטה שלנו. **זה מה שבונים.**
- **(ב) מקלדת‑מערכת (IME)** — רכיב OS שעובד בכל האפליקציות, מוגבל מאוד, קשה. **לא בונים.**

## 2. מחקר — דאטה להשלמה‑חכמה (חוקר #2)
**זה הנכס.** האפליקציה עשירה בדאטה תחומית שאפשר להזרים ל‑autocomplete:

- **קטלוג ~1,872 מוצרים:** ליפסקי 923 (`lipskey_catalog.dart`) · פולירול ~779 · חוליות ~170. שדות: `sku`(מספרי, למשל 217861), `nameHe`, `categoryHe`, `brand`, `dims`, `color`.
- **🔑 `lipskeyWordIndex()`** (`lipskey_catalog.dart:474`) — **אינדקס‑מילים הפוך מוכן (word→SKUs), lazy, min‑2‑תווים.** מנוע‑autocomplete מוצרים **מן‑המוכן** — שימוש‑חוזר ישיר.
- **`search_index.dart`** — 350+ ערכי‑ניווט (טאבים/personas/הגדרות/קטגוריות) עם `contains()` — autocomplete ניווט.
- **8 מותגים** (`brands.dart`): AQUATEC · ליפסקי ברקן · פלסון · חגור · גרוהה · חמת · פולירול · חוליות. **13 קטגוריות** (`catalog.dart`, עם emoji).
- **ישויות לשמות:** עובדים (רן/עומר) · לקוחות (אלי בניין בע״מ, קבלן דוד שמש...) · אתרים (מגדל הרצליה...) · צי (V14/אבי...).
- **📌 מס׳‑הזמנה = `BS‑####`** (לא ה‑SKU! SKU מספרי). מהצ׳אט: "מתי אפשר לאסוף את **BS‑1041**?".
- **משפטים‑מוכנים (canned) — כבר בקוד:**
  - תוויות‑שלב (`kOrderStageLabel`): "מוכן לאיסוף" · "בדרך לאתר" · "נמסר ✓".
  - seed‑צ׳אט (`chat_seeds.dart`): "מוכן לאיסוף מהמחסן מ‑14:00." · "אישור הזמנה #1234 — מוכנה לאיסוף ✅" · "ההזמנה שלך תצא בעוד כ‑20 דקות."
  - סטטוסי‑משימה · טיפי‑בטיחות (`contractor_seeds.dart`).

## 3. מחקר — תשתית‑קלט קיימת (חוקר #3 ✅) — **הרבה מן‑המוכן**
- **🎤 קול כבר עובד:** `VoiceService` (`services/voice.dart`, חבילת `speech_to_text:^7.0.0`, he‑IL) — מחווט להכתבת‑הערות‑עובד. **אבל קול בצ׳אט = stub** (`_showVoiceUnavailable`, `chats_screen.dart`). → לחבר את ה‑service לרצועת‑הכלים (ובדרך לסגור את ה‑stub בצ׳אט). שימוש‑חוזר‑גבוה.
- **📷 ברקוד מן‑המוכן:** `openBarcodeScanner(context)→Future<String?>` (`barcode_scanner.dart`, `mobile_scanner:^5.2.3`) + הזנת‑SKU ידנית. → כפתור "ברקוד→הוסף‑SKU" ברצועה.
- **🔘 chips לשימוש‑חוזר:** `_FilterChipsRow`+`_Pill` (`chats_screen.dart:752`) — pills אופקיים תלויי‑audience. **בסיס מושלם לרצועת‑ההצעות.**
- **✍️ הזרקת‑טקסט מן‑המוכן:** `_insertText(controller, text)` + emoji‑picker (`chats_screen.dart:1949`) — מזריק בקרסור. **בדיוק מה שצריך ל"tap‑על‑chip→הכנס‑משפט".**
- **🔢 stepper כמות:** `_SmartQtyStepper` (`store_screen.dart:1941`) — ±/qty inline, לשימוש‑חוזר במספרי.
- **composer צ׳אט (`_InputBar` `:2016`):** כבר מצלמה+attach+emoji+send/mic — תבנית "רצועת‑כלים" קיימת (חלק stubs).
- **🔐 לוח‑ספרות — לא קיים** (רק validators: `validBoardCode` 4‑ספרות, `normalizeIlPhone`, `validEmail` ב‑`input_validators.dart`). → לוח‑מאובטח = בנייה חדשה.
- **i18n:** `enum BsLang{he,ar,en}` + locale ב‑`main.dart:332` (he‑IL/ar/en‑US) + delegates. **RTL קשיח בשורש** (`main.dart:372`). אבל תרגומים כמעט‑ריקים (`l10n/smart_card_strings.dart` לא מחווט), קול he‑IL בלבד.
- **♿ נגישות מקיפה (חובה לכבד):** `Semantics(button,label)` + ≥48dp + `textScaler` (`main.dart:358`) + `disableAnimations`(reduceMotion) + highContrast (`bsOnAccent`/`bsSuccess`). **אין package מקלדת — בנייה על Flutter primitives, אפס deps חדשים.**

## 4. התכנון — "המקלדת המושלמת ל‑BuildSmart" (3 שכבות)

**שכבה 1 — רצועת‑הצעות חכמה** (אופקית, גלילה, מעל מקשי‑המערכת; תלוית‑הקשר):
- צ׳אט → quick‑replies מ‑`kOrderStageLabel`+`chat_seeds` ("מוכן לאיסוף מהמחסן מ‑__", "מתי אפשר לאסוף את [BS‑####]?", "אישור הזמנה #__ ✅") + מס׳‑הזמנות אחרונים + הוסף‑מוצר.
- חיפוש → autocomplete מוצרים/קטגוריות/מותגים מ‑`lipskeyWordIndex`+`kCatalogCats`.
- מספרי → chips יחידות (מ"מ · ס"מ · מ' · ק"ג · יח') + ערכים‑נפוצים.
- שם/כתובת → ישויות ידועות (לקוחות/אתרים/עובדים).

**שכבה 2 — רצועת‑כלים** (ה"פיצ'רים במקלדת במקום במסך"): צרף‑תמונה/POD · ברקוד→הוסף‑SKU · קול→הכתבה · הוסף‑הזמנה# · הוסף‑מוצר · יחידות · אימוג'י · שלח. מאחד כפתורים מפוזרים → מסך נקי (R2).

**שכבה 3 — מקשים‑מותאמים (רק שדות רגישים):** **לוח‑ספרות מאובטח in‑app** ל‑OTP(6) / קוד‑לוח / סיסמה / תשלום — "ההקלדה לא יוצאת מהאפליקציה". **לא גלובלי.**

## 6. שלבים + מאמץ + גידור
- **שלב 1 — רצועה‑חכמה + autocomplete** (ערך‑גבוה/סיכון‑נמוך): מקשי‑מערכת נשארים; מחברים רצועה ל‑`lipskeyWordIndex`+canned+קטגוריות+מס׳‑הזמנה. **~80% מהחזון ב‑20% מהמאמץ**, ושומר קול/RTL/נגישות. `kSmartInput` OFF.
- **שלב 2 — לוח‑ספרות/יחידות מאובטח** לשדות CODE/NUMERIC/תשלום (אבטחה+מהירות+כפפות).
- **שלב 3 (אופ׳) — מקשי‑אותיות מלאים משלנו** רק אם "ההקלדה לא יוצאת מהאפליקציה" נדרש לכל שדה (כבד: חוב מלא עברית/RTL/קול/נגישות).

## 7. סיכונים / אילוצים
- **נגישות** (חובה חוקית IL, ברשימת‑ההשקה): שלב‑1 משמר; שלבים 2‑3 חייבים `Semantics`+textScaler מחדש.
