## 0. סקירה כללית
**מה זה:** פלטפורמה שמחברת את שרשרת-האספקה של אינסטלציה/בנייה — קבלן · חנות · שליח · עובד · מנהל — באפליקציה אחת (iOS/Android/Web), עברית RTL, סגנון-וואטסאפ.
**הבעיה:** קבלן עובד היום בטלפונים/וואטסאפ/אקסל; אין מקור-אמת אחד לקנייה, מעקב, ניהול-אתר ותקציב.
**הפתרון:** קנייה-חכמה ברצף + מעקב-הזמנה חי חוצה-תפקידים + ניהול-פרויקט מלא — במסך אחד.

**עקרונות-על (חלים על כל המוצר):**
| עקרון | הסבר |
|-------|------|
| מקור-אמת אחד | כולם רואים אותה הזמנה/סטטוס בזמן-אמת |
| verbatim | טקסטים+מספרים מהמקור, בלי המצאה |
| RTL-first | עברית, גופן Heebo, כתום-מותג #FF7A18 |
| server-ready | כל נתון דרך Repository → חיבור-שרת = drop-in |
| כנות | פקד שלא עובד = honest-stub, לא toast-מתחזה |
| נגישות-שטח | כפתור ≥52px · קולי · ניגודיות-גבוהה · רטט |

**5 פרסונות:** 👷 קבלן · 🏪 חנות · 🛵 שליח · 🦺 עובד · 👔 מנהל.

## 2. מודול: קטלוג + הזמנת-רץ (Batch Order) — החוויה המרכזית

### 2.1 תיאור
הקבלן/עובד מזמין עשרות מוצרים ברצף תוך-כדי-עבודה, בלי לעזוב את המסך — חוויית "סופר". קטלוג **1,877 מוצרים** (Lipskey 935 · Polyroll 772 · Huliot 170) + HW-133 חימום-מים.

### 2.2 עקרונות מנחים
| עקרון | הסבר |
|-------|------|
| רצף בלתי-מופרע | נשארים באותו מסך — לא קופצים לסל |
| משוב מיידי | כל הוספה = אנימציה + רטט + צליל |
| ערימה מצטברת | "הוזמן-עכשיו" רץ למעלה, תמיד גלוי |
| מינימום קליקים | ≤3 קליקים מפתיחה להוספה |
| סל-לכל-פרויקט | הרצף שייך לפרויקט-הפעיל |
