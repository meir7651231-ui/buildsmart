### Step 6 — `ConfigStore` notifier + `ConfigSink`/`LocalPrefsSink` + draft/publish API
**NEW** `lib/state/studio/config_store.dart`

1. 🎯 **היעד** — `StateNotifier<ConfigDoc>` עם `editDraft`/`resetDraftNode`/`discardDraft`/`publish`/`rollback`, sink מוזרק (seam ל-Pillar-5), persist ל-`'bs.studio-config.v1'`; publish גוזם nodes ריקים ודוחף version; doc ריק לא מאחסן כלום חדש.
2. 🔧 **איך בונים** — שכפול byte-for-byte של `_load`/`_persist` מ-`catalog_settings.dart:374-389` (`unawaited(_load())` ב-ctor, `try/on Object catch(_)`). `ConfigSink{Future<void> save(ConfigDoc); Stream<ConfigDoc>? watch()}` עם `LocalPrefsSink` default. `publish`: prune (`CfgNode.isEmpty`) → snapshot ל-`history` (cap `kHistoryCap`) → draft←published-cleared → `_sink.save` + publish-event. Providers: `configSinkProvider` + `configStoreProvider`.
3. ⚠️ **תקלות צפויות** — (א) `publish` לא גוזם ⇒ docs נפוחים. (ב) `rollback` הורס היסטוריה במקום להוסיף version קדימה. (ג) שתי כתיבות מהירות ⇒ race ב-`_persist` (write אחרון מנצח, אובדן draft). (ד) `editDraft` mutate-in-place את ה-Map ⇒ Riverpod לא משדר (אותה הפניה).
