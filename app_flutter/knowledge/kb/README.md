# מאגר-הידע (KB) — app_flutter

הזיכרון-המוסדי של הפרויקט: **עובדות, לא דעות.** מתוחזק ע"י **סוכן-הידע**.

## העיקרון הקריטי
לאף סוכן אין זיכרון בין sessions. **הידע חי כאן (בקבצים), לא בראש של אף סוכן.**
כל ידע חדש → נכתב לכאן מיד. כל שאלה → נענית מכאן + מצוטטת.

## כללי סוכן-הידע
- ענה **רק** מהמאגר, ומצטט מקור. לא במאגר → "לא תועד" (אל תנחש).
- שמור מדויק / עדכני / שלם. סתירות → יישב. ישן → גזום.
- **דעות/זוויות הן לא תפקידך** — זה פאנל-הסימולציה. אתה מוסר **עובדות**.
- הפרוטוקול/השערים שייכים לפרוטוקוליסט (`VERIFICATION_PROTOCOL.md`, ה-hook). אתה מחזיק **ידע** (מפות, חיווט, לקחים), לא את הגדרות-הפרוטוקול.

## הקבצים
- `ownership-and-traps.md` — מי מחזיק מה · קבצים-חמים · מלכודות שערים/git.
- `wiring-map.md` — מה מחובר / מה לא / לאן צריך · ה-state האמיתי מול המת.
- `lessons.md` — לקחי-עבודה · מציאות-התיאום (אין ערוץ-חי) · ציר-זמן.
