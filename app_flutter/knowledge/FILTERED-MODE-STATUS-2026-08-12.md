## המטרה
האתר שמיש במלואו על אינטרנט-מסונן (‏Netfree/Rimon/Etrog) — **כל** התעבורה דרך
הדומיין המאושר `buildsmart-il.com` ותת-הדומיינים שלו, **אפס** בקשות ל-
`googleapis.com` (הסנן חוסם). לכן נבנתה שכבת-REST מקבילה דרך מתווך-קצה
(Cloudflare Worker) על תת-דומיינים: `fs.`/`idt.`/`token.`/`fn.`/`api.`.

## 🔑 חוק-העל של מצב-מסונן (השורש של כל הבאגים בסשן הזה)
**בקו-מסונן — כל קריאת/כתיבת-נתונים חייבת לעבור REST (הגשר), לא ה-Firebase SDK.**
ל-SDK אין טוקן-Auth תקין דרך המתווך ⇒ כל `snapshots()`/`get()` שלו **נדחה בשקט**
(ה-listener הממוגן בולע את השגיאה) ⇒ מסך ריק / 0 תוצאות, בלי הודעת-שגיאה.
כל ספק שקורא `FirestoreCollectionSource(...)` **חייב** ענף-מסונן:
```dart
final rest = ref.watch(filteredFirestoreProvider);
if (rest != null) return EdgeRestCollectionSource('<collection>', rest);
```

## ✅ מסלול-הלקוח המרכזי — סגור ומאומת
התחברות (מייל+סיסמה REST) → הרשמה → אישור/טענה → הזמנה → **צ'אט דו-כיווני** →
**רשימת-אנשים ל"שיחה חדשה"**. כל אלה עוברים REST ועובדים בקו-מסונן.

הקבצים שכבר עוברים REST: `state/auth_state` · `data/repositories/orders_local` ·
`data/repositories/chat_repository` · `state/role_requests` · `state/directory` ·
`data/repositories/users_lookup`.

## ⏭️ נותר (סריקה יזומה — קבצי SDK-בלבד שעלולים להישבר בסינון)
לפי חומרה ללקוח-מסונן:
1. **`site_firebase.dart`** — כלי-אתר/פרויקט של הקבלן (`siteNodes`/`siteStageProgress`).
   **הכי-סביר הבא** אם הלקוח-הקבלן פותח פרויקט/אתר. → לנתב דרך REST באותו דפוס.
2. `studio_config_firebase.dart` — `studioConfigLive/current` (טקסטי-UI שהבעלים
   פרסם, public-read). סיכון-נמוך: נופל לברירת-מחדל, לא "שבור".
3. `push_state.dart` — טוקן-פוש (כתיבה). סיכון-נמוך לתצוגה.
4. **אפס-סיכון ללקוח** (Rules חוסמים ממילא, מנהל/חנות/עובד בלבד):
   `customers_firebase` · `finance_firebase` · `stock_firebase` ·
   `material_requests_firebase`.

**המלצה למחר:** אם הלקוח משתמש בפרויקטים/אתר — לנתב את `site_firebase` דרך REST
(דפוס זהה ל-#54). אחרת מסלול-הלקוח כבר שלם; אפשר לעבור לנושא הבא.

  **נעשה** (‏fs./idt./token. מנותבים; הצ'אט עובד = הוכחה).

  **עקפנו** את התלות ב-#52 (הסרנו את ה-orderBy). אם רוצים "newest-500" אמיתי
  לשרשורים ענקיים — צריך שהבעלים יפרסם אינדקס תואם; לא חוסם היום.
