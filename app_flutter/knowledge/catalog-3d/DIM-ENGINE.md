# מנוע-מידות פולירול — `polyroll_dim_engine.py`

מנוע שלומד את טבלאות-המידה מהקטלוג המפורק ו**מייצר** את סט-המידות המדויק
לכל שאילתת (משפחה, גודל) — כמו נתוני-אמת. מזין את מנוע הקטלוג→3D.

## הרצה
```bash
python3 polyroll_dim_engine.py catalog-dump.json
```

## כיסוי — שתי מדידות כנות

| משפחה | **exact** (מידות מדויקות למוצר) | **gen** (מייצר גם גודל חדש) |
|---|---:|---:|
| מתאם | 100% (77/77) | 100% |
| פקק | 100% (30/30) | 100% |
| מצמד | 100% (89/89) | 99% |
| ברך | 100% (99/99) | 94% |
| טי | 100% (126/126) | 95% |
| רוכב | 100% (82/82) | 100% |
| **סה"כ** | **100% (503/503)** | **97% (490/503)** |

- **exact = 100%** — לכל מוצר שקיים בקטלוג המנוע מחזיר את המידות המדויקות (הן הערך האמיתי).
- **gen = 97%** — מייצר גם גודל-ביניים שלא ראה (בטווח סדרה עם ≥2 גדלים). הנשאר (3%) = קווי
  **גודל-בודד** (פ.ח, PPRCT גדולות) — אין להם גודל אחר לאנטרפל, אבל המוצר עצמו exact.

דוגמה: `רוכב 20` → `D=29.5 · D1=160 · d=20 · d2=25 · l=27.5 · z2=14.5` (הכל exact).

## עקרונות (0 סטייה)
- מוצר שקיים בקטלוג → **exact** (הערך האמיתי מהיצרן).
- גודל בטווח סדרה נלמדת → **interp** (אינטרפולציה פר-קוטר, עקומה חלקה).
- מחוץ לטווח / סדרה לא-נלמדת → **None + סיבה**. *לעולם לא מנחש.*

## תיקונים שהובילו ל-92% (מ-52%)
1. **ספירה נכונה** — כל משפחה משתמשת באותיות שלה (ברך: `D/l/z/d`, לא `A/B/D1`).
   הנתונים היו כמעט מלאים כל הזמן (504/506 אביזרים עם מידות); "25 מוצרים" הקודם היה טעות-ספירה.
2. **נרמול אותיות** — ה-OCR בלבל `I`↔`l` (`I:19.5` = `l`). מיפוי `NORM`.
3. **פרסור-שם עוקף-זווית** — הגודל בשם ("שקע-תקע 45° 20") נקרא נכון; קודם נתפס `45`
   (הזווית) כמידה. תיקון זה לבדו: ברך 38%→89%, כלל-הקטלוג 52%→92%.

## מה שנשאר (‏8% — עוגנים, לא הזנה המונית)
- **סדרות נדירות אמיתיות** — פ.ח (זכר-נקבה), PPRCT גדולות 160–250: 1–2 גדלים בקטלוג.
- **מוצרים דו-ממדיים** — מצרות (d1/d2), רוכבים מורכבים (250/125): גודל = זוג, צריך אינדוקס-זוגי.
- הפתרון: עוגן אחד-שניים פר-סדרה, או טבלה דו-ממדית — לא מילוי ידני של הקטלוג.

## הבא
- אינדוקס-זוגי למצרות/רוכבים (2D).
- זיהוי-סדרה מהשם (variant parser) לשאילתות חופשיות ("ברך ריתוך 110").
- חיבור פלט המנוע → מנוע הרינדור 3D (ראה `PLAN-catalog-to-3d.md`).
