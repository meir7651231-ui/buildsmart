# אב-טיפוס — קטלוג → 3D (הדגמה)

קבצי HTML עצמאיים (WebGL בעבודת-יד, בלי ספריות). פותחים בדפדפן. **הדגמה בלבד — לא קוד מוצר.**

| קובץ | מה רואים |
|---|---|
| `catalog-engine.html` | בוחרים SKU מרשימה → 3D מתחולל חי. 5 תבניות פרמטריות. |
| `assembly-3d.html` | קו אינסטלציה מורכב ב-3D, כל מפרק מתויג בשיטת-חיבור + BOM + סליידר פיצוץ. |
| `adapter-tospec.html` | מתאם 6702000200 נאמן-למידות 1:1 מ"מ, 3D מסתובב לצד חתך מדוד. |
| `gen3d.html` | **מנוע טהור → 3D → תכנון חיבור.** 2 מצבים: (1) **אביזר בודד** — בוחרים משפחה+גודל, המנוע מחשב את כל האותיות מחוקי-תכן (0 נתוני-קטלוג), בונה 3D, והצינור נכנס לשקע. (2) **תכנון חיבור** — בונים רצף (➕ חבר / ✂️ נתק), ברך מנתבת ‎90°/45°, ומחוון 💥 מפוצץ כל מפרק. 10 משפחות: מצמד · ברך 90°/45° · טי · מתאם תבריג · ברז כדורי · מצרה · פקק · רוכב · צווארון. פורט-JS מדויק של `../pure_engine.py`. |
