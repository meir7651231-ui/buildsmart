# קונסטרוקציה הנדסית — כל אות מהשרטוט (מנוע טהור)

מפוענח מהשרטוטים הטכניים בקטלוג פולירול. **כל אות = מיקום גיאומטרי, לא נתון ולא fit.**
`pure_engine.py` מיישם. דיוק ~1.3 מ"מ (רצפת עיגול-התקן) — מושלם ל-3D.

## הבסיס האוניברסלי (כל אביזר-ריתוך)
| אות | קונסטרוקציה | מקור |
|---|---|---|
| OD | הקוטר הנומינלי | הצינור |
| wall | `OD/SDR` | תקן SDR |
| ID (קדח-זרימה) | `OD − 2·wall` | הצינור מבפנים |
| **B/D** (קוטר-חוץ) | `OD·(1+2/SDR) ≈ 1.33·OD` | שקע = צינור + דופן |
| **C** (קדח-שקע) | `≈ 0.97·OD` | הצינור נכנס |
| **F** (עומק-שקע) | טבלת ריתוך DIN 8077 | תקן |

## צורה פר-משפחה (z = מרכז-לפָּנים)
- **מצמד:** `A = 2·F + מעצור(~2)`.
- **ברך:** `z = R·tan(θ/2)` · `R ≈ 0.52·OD` · `l = F + z`. **45° נגזר מ-90° דרך tan — גיאומטריה, לא fit.**
- **טי:** `z ≈ B/2` · `E = 2·(z+F)` (רץ) · `A = z + F + B/2` (הסתעפות).

## הוכחה (מהשרטוט)
- `l − z = F` (עומק-ריתוך אוניברסלי) — מאומת 10/10.
- `z45 = z90·tan22.5/tan45` — חציון 0.5 מ"מ, **בלי לראות נתוני 45°**. תופס את d=125 החריג.

## רצפת ה-1.3 מ"מ
בדוק ב-3 שיטות עצמאיות (fit · יחס-הנדסי · קונסטרוקציה-מהשרטוט) — כולן עוצרות ~1.3 מ"מ.
זה **עיגול-התקן הידני** פר-גודל, לא כשל-שיטה. ל-3D בלתי-נראה; למפרט-מדויק צריך את הטבלה.

## ממתין לפיענוח-שרטוט (thread/body)
- **מתאם:** תבריג (A/B/E/F/G/R) — עוגן לגודל-התבריג (½/¾/1"), לא ל-OD.
- **ברז:** גובה גוף/ידית (h/H/L2/L3) — פר-סוג-ברז.
