# קונסטרוקציה הנדסית — כל אות מהשרטוט (מנוע טהור)

מפוענח מהשרטוטים הטכניים בקטלוג פולירול. **כל אות = מיקום גיאומטרי, לא נתון ולא fit.**
`pure_engine.py` מיישם. דיוק ~1.3 מ"מ (רצפת עיגול-התקן) — מושלם ל-3D.

## הבסיס האוניברסלי (כל אביזר-ריתוך)
| אות | קונסטרוקציה | מקור |
|---|---|---|
| OD | הקוטר הנומינלי | הצינור |
| wall | `OD/SDR` | תקן SDR |
| ID (קדח-זרימה) | `OD − 2·wall` | הצינור מבפנים |
| **B/D** (קוטר-חוץ) | `OD·(1+2/SDR) ≈ 1.33·OD` | שקע = צינור + דופן |
| **C** (קדח-שקע) | `≈ 0.97·OD` | הצינור נכנס |
| **F** (עומק-שקע) | טבלת ריתוך DIN 8077 | תקן |

## צורה פר-משפחה (z = מרכז-לפָּנים)
- **מצמד:** `A = 2·F + מעצור(~2)`.
- **ברך:** `z = R·tan(θ/2)` · `R ≈ 0.52·OD` · `l = F + z`. **45° נגזר מ-90° דרך tan — גיאומטריה, לא fit.**
- **טי:** `z ≈ B/2` · `E = 2·(z+F)` (רץ) · `A = z + F + B/2` (הסתעפות).

## הוכחה (מהשרטוט)
- `l − z = F` (עומק-ריתוך אוניברסלי) — מאומת 10/10.
- `z45 = z90·tan22.5/tan45` — חציון 0.5 מ"מ, **בלי לראות נתוני 45°**. תופס את d=125 החריג.

## רצפת ה-1.3 מ"מ
בדוק ב-3 שיטות עצמאיות (fit · יחס-הנדסי · קונסטרוקציה-מהשרטוט) — כולן עוצרות ~1.3 מ"מ.
זה **עיגול-התקן הידני** פר-גודל, לא כשל-שיטה. ל-3D בלתי-נראה; למפרט-מדויק צריך את הטבלה.

## ממתין לפיענוח-שרטוט (thread/body)
- **מתאם:** תבריג (A/B/E/F/G/R) — עוגן לגודל-התבריג (½/¾/1"), לא ל-OD.
- **ברז:** גובה גוף/ידית (h/H/L2/L3) — פר-סוג-ברז.

## מתאם (תבריג) — עוגן כפול
נקרא מהשרטוט: **הצד-שקע** ← d (עומק F, קדח C). **הצד-תבריג** ← גודל-התבריג R:
- `SW` (מפתח משושה) = תקן BSP: 1"→32 · 1¼"→41 · 1½"→46 · 2"→50 · 2½"→65 · 3"→85.
- `D`/תבריג-OD ← R (לא ל-OD). `z`,`L` = שילוב שני הצדדים.

## ברז — גוף + כדור + ידית
- גוף שקע-שקע: `l = z + F` (כמו מצמד, z גדול כי הכדור באמצע).
- `dk` (קדח-כדור) ≈ `DN` (הספיקה הנומינלית).
- ידית: `h`,`H`,`L1` — גיאומטריית-ידית פר-גודל (עיצוב).

## ⚠️ ריבוי-דיאגרמות (מודלים) — עקרון חשוב
משפחה אחת יכולה לשאת **כמה קונסטרוקציות לפי טווח-גודל**:
- **ברך 20–125** = יצוקה (l/z/D). **ברך 160–400** = מודל A (יצוק, A/B/C/D) או **מודל B מחותך** (E/F/G — מגזרים בזוויות).
- מצרות (d1×d2) = דיאגרמה נפרדת (דו-ממדית).
לכן המנוע צריך בורר: `family → (טווח-גודל → קונסטרוקציה/דיאגרמה)`. הקונסטרוקציות כאן = הסדרה
היצוקה (AQUATHERM, 20–125). הגדולות (Heliroma, 160–400) = דיאגרמות נפרדות לפענוח.

## מודל-B מחותך (ברך 160–400) — גיאומטריה טהורה, ~0 סטייה
מגזרים חתוכים בזוויות → אורכים = יחס נקי ל-d (מהרדיוס והמיתרים):
`A=3.0·d · G=1.377·d · F=1.186·d · E=0.765·d`. עקביות מדהימה (G: 1.378/1.377/1.377).
**מחותך מדויק יותר מיצוק** — כי זו גיאומטריה, בלי עיגול-יציקה.

## מצרה (d1×d2) — קומפוזיציה, לא חוק חדש
המצרה = **שני צדדים, כל אחד לפי base של הקוטר שלו**:
`B1=1.33·d1 C1=0.97·d1 F1=עומק(d1)` · `B2=1.33·d2 …` · `A=F1+F2+מעבר`.
המנוע מרכיב `base(d1)+base(d2)` — אפס חוקים חדשים.

## סיכום — טקסונומיית הקונסטרוקציה (הכל מפוענח)
| סוג | קונסטרוקציה |
|---|---|
| אביזר-ריתוך יצוק | base + צורה (z) — ~1.3 מ"מ (עיגול-תקן) |
| ברך מחותכת גדולה | מגזרים = יחס נקי ל-d — ~0 מ"מ |
| מצרה | קומפוזיציה של 2 base |
| מתאם | base(שקע) + תבריג(תקן BSP) |
| ברז | base + כדור(dk≈DN) + ידית |
| בורר | `family → (טווח-גודל → קונסטרוקציה)` |

## טבלת-אב — לולאה על כל המשפחות × כל האותיות
`master_ratios.py` → `construction_ratios.json`. עבר על כל 627 האביזרים, 10 משפחות, 174 אותיות.
**קבועים אוניברסליים שאושרו על כל הקטלוג:**
- `D` (קוטר-שקע) = **1.33·d** — בכל המשפחות (ברז·ברך·טי·מתאם·פקק·רוכב).
- `C` (קדח) ≈ **0.97–1.0·d** · `B` = **1.33·d** · `d2` (קדח-2) = **1.0·d**.
- `z` תלוי-זווית: ברך45=0.237·d · ברך90=0.58·d · טי=0.53·d — `z=R·tan(θ/2)`.
