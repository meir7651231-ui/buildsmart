# תוכנית — מקטלוג ל-3D בהיקף מלא

> תוכנית-אב לסוכן הביצוע. הגישה הוכחה באב-הטיפוס (`prototypes/`). מה שנשאר הוא **נתונים + הטמעה**, לא מחקר.

## המנוע — 3 שלבים לכל מוצר

```
שורת קטלוג ──▶ (1) קטגוריה→תבנית ──▶ (2) מידות→פרמטרים ──▶ (3) חומר→PBR ──▶ mesh
```
1. `categoryHe`/`kPpr*` → `TEMPLATES[key]` (adapter/coupler/reducer/elbow/tee/plug/collar/saddle/pipe/clamp/flange).
2. אותיות `A/B/D1/D2/E/F/G/R` → קודקודי `revolve`/`hexRod`/`sphere`, בקנה 1:1 מ"מ.
3. `material`/`color` → resolver PBR (PPR ירוק · פליז · נחושת · HDPE שחור).

## Phase 0 — חילוץ נתונים (צוואר-הבקבוק האמיתי)

מצב: 25/758 מלא, 137 חלקי. STAGE 2 (עמ' 35–92 ב-PDF) ממתין.
**שתי דרכים:**
- **A. פרסר PDF לטבלאות** — לבנות (אין כזה בקוד). קלט: `PolyrollHeliroma_HE_020325.pdf`. פלט: `{sku: {A,B,D1,...}}`. מומלץ — סקלבילי.
- **B. המשך תמלול ידני** — כמו STAGE 1. איטי אבל ודאי.
- **QA:** לחסום ערכים לא-עקביים לפני רינדור (ראה ממצאי איכות ב-SUMMARY §6): חסר `A`, `R` חריג.

## Phase 1 — מיפוי משפחות→תבניות

טבלת `kPpr*`/`categoryHe` → template key. ~12–14 תבניות. ראה SUMMARY §3 להתפלגות ולכיסוי (~70%).
מה שלא ממופה = fallback לתמונת מוצר (כבר קיימת — 1,543 תמונות).

## Phase 2 — נרמול מפתחות-מידה פר-מותג

כל מותג שומר מידות אחרת (פולירול: אותיות; ליפסקי: `dims` map; טקסט-חופשי ב-`catalog-dump.json` עמודה G). שכבת תרגום אחת → סכימת-אות קנונית `{A,B,D1,D2,E,F,G,R}`.

## Phase 3 — הטמעת מנוע-הרינדור ב-Flutter

אב-הטיפוס הוא WebGL/JS. באפליקציה (Flutter) האפשרויות:
- **glTF מחולל + `model_viewer_plus`** — לייצר glTF פר-משפחה מהאותיות, להציג. (מומלץ — מנתק ייצור מתצוגה.)
- **`flutter_scene`/`flutter_gl`** — רינדור נייטיב, אותה מתמטיקה כמו האב-טיפוס.
- **CustomPainter דו-ממד** — אם 3D-מלא מוגזם: חתך מדוד בלבד (כמו `adapter-tospec.html` צד שמאל).
המלצה: להתחיל מ-glTF מחולל — מאפשר caching פר-SKU ובלי מנוע-ריצה כבד.

## Phase 4 — חיבור למוצר

- כרטיס מוצר בקטלוג: כפתור "תצוגת 3D" → מנוע (או glTF cache).
- **תכנון חיבור** (`install_studio_screen`): להפוך את ה-BOM לתצוגת-הרכבה חיה (כמו `assembly-3d.html`) — נהנה מ-`EndType` שכבר קיים ב-`install_engine.dart` (891 מפרטים). ראה SUMMARY §7.
