# WIRING-SSOT — האפיון המשותף לחיווט הכרטיס-הפנימי (BuildSmart)
> הארטיפקט שכל צומת בנחיל 9×9 צורך. מקור-אמת יחיד להחלטות-העיצוב.
> קוד-מקור לצד זה: `app_flutter/lib/screens/lipskey_product_sheet.dart` (הכרטיס-הפנימי),
> `app_flutter/lib/data/related_info.dart` (מנוע התאימות + ends), `variant_families.dart`,
> `features/ring_dive/catalog_axes.dart` (catAxesOf), `features/word_finder/*` (super-finder),
> `features/catalog_config/*` (קלף הקונפיג), `app/` (האתר החי).

## North Star (מעל הכל)
- האפליקציה = מנוע ריק. כפתור מוחק הכל → מעלים קובץ-ספק שתואם לחוזה-הנתונים → רץ.
- המחיר מגיע מקובץ הספק, לא מהקוד. הכל data-driven → שורד wipe-and-reload.
- "לזקק את המראה, להסתיר את המנוע": הלוקח רואה מסך יפה; super-finder/ציפים/צירים רצים סמוי; אפס אובדן יכולת.
- כל תוספת מגודרת `bool.fromEnvironment('FLAG')` ברירת-מחדל OFF → tree-shaken → בייט-זהה ל-live.

## ההחלטות (18) — כל אחת: מה זה · האינטראקציה · לְמה מתחבר במנוע

### D1 · בסיס הכרטיס
תמונה-מייצגת במרכז (hero) ממלאת את הכרטיס · שם נקי · תת-שורה (זווית·מידה·צבע, נגזר מהשם) · רכישה למטה.
מנוע: `p.nameHe`, best-representative image (לא black — `isTrueColor`), תת-שורה מ-`nameChips`/catAxesOf.

### D2 · אייקוני-פינה עליונים (מודגשים, אייקון-בלבד, ממורכזים מעל עמודות)
- ימין: ← חזור (כתום, עבה, SVG). מרכז: מק"ט **מוטבע כמספר על התמונה** (בלי המילה "מק"ט", בלי אייקון). שמאל: 📋 מפרט/תקן/אזהרה.
מנוע: `p.sku` (מוטבע), copy-sku (`מק"ט הועתק` קיים בקוד).

### D3 · נגיעה בתמונה → גלריה
3 תמונות: **תלת-ממד מימין · מוצר במרכז · מפרט משמאל**. ✕ למעלה-במרכז. זום למטה.
מנוע: image gallery + pinch-zoom + multiple spec images (`התמונה הבאה`/`המפרט הבא` בקוד); תלת-ממד = לאתר.

### D4 · משיכת התמונה ↔ → תואמים (מה מתחבר לכל צד)
משיכה ימינה = מתחבר לצד ימין; שמאלה = צד שמאל. רכבת תמונות עגולות נגללת אנכית. תמונות בלבד.
מנוע: `compatibleProductsFor` / `_reallyMates` **פר-קצה (end)** — כאן הכיוונים קריטיים.

### D5 · משיכת השם ↔ → וריאנטים
אותו מוצר, מידה/צבע אחר (32→40→50→63). נקודות-מיקום קטנות (pagination) תחת השם. התמונה גדֵלה עם המידה. השם נשאר; תת-השורה+מחיר משתנים.
מנוע: `variantSiblingsOf` / `productCanonicalKey` (משפחת הווריאנטים).

### D6 · כפתור-חכם (הוסף לסל) — 4 כיוונים, נקי, בלי חצים/מלל
משיכה לצדדים = **יחידת הזמנה** (יחיד/קופסה/משטח) · מעלה/מטה = **כמות** · נגיעה = הוסף. הכפתור מציג רק מצב נוכחי (יחידה·מחיר).
מנוע: unit selector בודד/ארגז/משטח + `כמות באריזה`/`כמות במשטח` (קיים בקוד); מכפיל מחיר.

### D7 · הוספה → עיגול קטן **מתחת לכפתור** (לא למעלה)
המוצר יורד לעיגול עגול קטן מתחת ל"הוסף לסל", ומתחתיו **רק הכמות**. התמונה נדחסת מעט.
מגע: לחיצה על עיגול = מדגיש+עורך (עולה למסך); לחיצה על ה**מודגש** = מסיר. אין כפתורי ×.

### D8 · ההירו = המוצר **האחרון** (מודגש)
המסך הגדול מראה תמיד את המוצר האחרון שנוסף/נבחר, מודגש. הקודמים = עיגולים קטנים אפורים.

### D9 · מחיר משתכלל + ירוק
כל הוספה/הסרה מחשבת מחדש; הכפתור **הופך מכתום לירוק = "אשר · סה"כ ₪X"**. כתום=יש-מה-להוסיף · ירוק=אשר.
מנוע: `priceFor` (מודע מע"מ ×1.17 · מטבע · ליחידה — קיים `formatCatalogPrice`).

### D10 · **+** בפינה שמאל-למטה (אייקון עבה, בלבד; מופיע רק אחרי המוצר הראשון)
פותח **בחירה מרובה** → רצף מסודר (ראה D11). מוסיף ערכה + קו.
מנוע: `installKitFor` (ערכה: חובה/אופציה/כלים +₪).

### D11 · בניית-קו = **גריד/עץ** (לא ליניארי) — מספור היררכי
ראשי 1·2·3 + הסתעפויות 2.1·2.2. כל חלק עם שם+מספר+תמונה. **תמונות בלבד** בתצוגת-הגריד.
**חוק ההזזה:** מניחים חלק על חלק + דוחפים **ימינה** → הנכנס=ראשי, הישן→ענף(.1); **שמאלה** → הנכנס=ענף, הישן נשאר ראשי; **למטה** (משאיר מקום ריק) → **קו חדש**. הזזה **פנימה/החוצה** (לא מעלה/מטה). ככל שהקו גדל — התמונות מתכווצות.
מנוע: `variant_families`/canonical-key לזיהוי; טופולוגיה חדשה (ends → adjacency).

### D12 · הגריד = **סודוקו** · **כיוונים קריטיים** (הליבה)
מתחיל טורי (קו אחד בשורה עליונה) → ממשיך לגריד (מטריצת משבצות). כל משבצת = תמונה בלבד.
**המיקום = הכיוון הפיזי:** צינור ישר (2 כיוונים) · **ברך מסובבת 90°** · **טי מסתעפת ל-3** · פקק=קצה (1). המשבצות מחוברות לשכנות (ימין/שמאל=אותו קו · מעלה/מטה=ענף). בקו ליניארי אי-אפשר לייצג — רק במטריצה.
מנוע (הקריטי): `VerifiedSpec.ends` · `directMatesWith` · `pipeSharedWith` · gender male/female · axis 'angle'/'transition' ב-catAxesOf. **חסר? → פער לתכנון (מנוע-כיוונים/ports).**

### D13 · הצעות (המנוע החכם)
נוגעים במשבצת ריקה → למטה מופיעות **רק ההצעות שמתחברות** לשכן (✓ ירוק = המנוע אימת התאמה למידה+סוג+כיוון). תמונות בלבד + מידה.
מנוע: `compatibleProductsFor` מסונן לפי הקצה הפנוי של השכן.

### D14 · שלושת הכפתורים החכמים (פותר-הקו)
- **קו** → בחירה מרובה + הצעות **לפי תפקיד**: אמצע (זורם דרכו) · סוף (סוגר קצה) · חיבור (מחבר שניים).
- **בדיקה** → בוחרים 2+; אם לא מתחברים (לא תקין) → **מציע את האמצע החסר** (רדוקציות/מתאם) שיחבר.
- **השלם** → שמים רק **קצוות** (1=ברך 1צול · 9=ברך 4צול), והמנוע **ממלא את כל האמצע לבד** (כל הצינורות+המעברים 1→4).
מנוע: `הוסף לקו`/`השלם קו`/`פתרון קו` (קיימים בכרטיס-הפנימי — line solver); `מתאים לתנאים שלי?`.

### D15 · פאנל 📋 מפרט/תקן/אזהרה — **מסך שקוף מעל** (inline, לא קופץ-נפרד)
נפתח כשכבה שקופה מעל הכרטיס המעומעם; ה-📋 **מודגש למעלה = כפתור הסגירה**. טאבים: 📐מפרט · 🛡תקן · ⚠אזהרה · 🧱חומר · 🌡טמפ' (התקנה — פתוח: כאן או ב-+).
מנוע: `engineeringSpecFor` (dn/di/PN20) · `complianceTriggersFor` (היתר 114783) · warnings · material (TPE/PPR/DZR/PPMD) · temp (90°C/70°C לגיונלה).

### D16 · יכולות מהכרטיס-הפנימי שאסור לאבד (מאומת בקוד — INSP)
בניית-קו/פתרון-קו · יחידת-הזמנה בודד/ארגז/משטח · גלריה+זום+תמונות-מפרט · "מתאים לתנאים שלי?" · מחיר מע"מ/מטבע/ליחידה (+כיוון רב-ספקי) · מונה "מוצרים תואמים"/"דומים=וריאנטים" · "נמצא ב" · "מה עוד צריך להתקנה?" · מק"ט+העתקה · עמוד-בקטלוג · מידע-מותג/חיטוי.

### D17 · הבחנות-אמת (מהקוד)
- "דומים" בקוד = **וריאנטים** (label דומים, value "$famCount וריאנטים") — כפילות; "דומים אמיתי" (חלופות: 45° במקום 90°, מותג אחר, פליז) **לא קיים** — החלטת-פתוח.
- כל מוצר **יש** תמונה (~99.6%); black = בחירה גרועה, לא חוסר — לבחור best-representative (family/sub-family/sub-category), לדלג על black.

### D18 · "הסתר את המנוע" — מיפוי מחוות
כל אלמנט נמשך לדבר אחר: תמונה↔=תואמים · שם↔=וריאנטים · כפתור↔=יחידה/↕כמות · +=קו/גריד. אין מאתר-על גלוי, אין ציפים גלויים; הלוקח מקבל תוצאה, המנוע סמוי.
