Where `knowledge/logic/` opens the **engines** and `knowledge/data/` opens the
**entities** they read, this closes the **floor**: the smallest pure
value-transformers an engine bottoms out on. The logic decomposer already lists
these as a `floor` line — *a name*. Phase P turns each name into a **contract**:

**name · file:line · signature · returns · EDGE cases · pure?**

The edge is the point — a primitive's real contract lives at its boundaries. Each
edge carries the *syntactic signal* that proves it in the body, so step 70's
`primitive_contract_test` maps every documented edge to an assertion.

## The one owner-decision here (not a refactor)

- **toast is impure and lives in `widgets/`, not `state/`** — `showToast`/
  `showGlobalToast` are the only NON-pure "primitives": they mutate the
  `ScaffoldMessenger` queue. The unmounted → no-op guard is deliberate (a
  foreground FCM payload can arrive before the app mounts). Documented, not moved.
- **the homeless price (#54)** links here: `groupThousands`/`formatNis` are the
  one true ₪ grouper, but the *amount* they format still has 3 disconnected
  representations upstream — see `knowledge/data/HARD-CASES.md`.

**Guards:** read-only · zero app-code change · the contract is documented, never
tightened. Each module dir holds `module.prim.json` + one `<module>.prim.md`
(the step-69 table + the step-70 edge→assertion list).
