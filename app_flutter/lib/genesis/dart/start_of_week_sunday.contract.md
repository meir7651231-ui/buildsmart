# חוזה · `startOfWeekSunday` (Dart)

מקור-אמת (קדוש, חוק-4): `buildsmart/app_flutter/lib/logic/calendar_days.dart:33-35`.
פונקציית top-level, אפס-שקעים (אין קריאה-לשכן; רק DateTime מובנה).

## חתימה
```dart
DateTime startOfWeekSunday(DateTime d)
```

## קלט
- `d` — DateTime כלשהו. `d.weekday`: שני=1, שלישי=2, … ראשון=7 (מוסכמת dart:core).

## פלט / התנהגות (עוגני-שורה)
- `calendar_days.dart:34-35` — `DateTime(d.year, d.month, d.day - (d.weekday % 7))`:
  - `weekday % 7` ⇒ ראשון=0, שני=1, שלישי=2, רביעי=3, חמישי=4, שישי=5, שבת=6.
  - התוצאה = חצות (00:00:00) של יום-הראשון של השבוע המכיל את `d`.
  - נשמר `d.year`/`d.month`; רק היום מוזז אחורה. `DateTime` מנרמל יום ≤ 0 ⇒
    גלישה-אחורה לחודש הקודם (ראשון-השבוע יכול ליפול בחודש/שנה קודמים).
  - רכיב-השעה של הקלט **נזרק** (הבנייה מ-y/m/d בלבד ⇒ תמיד 00:00:00.000).
