# חוזה · `minBoreOf`

> אטום-Dart. מוצא: `buildsmart/app_flutter/lib/logic/pressure_drop.dart:104-114`
> (חוק-4 — התנהגות זהה למקור, לא-משופרת).

## תיאור
מחזיר את הקוטר-הפנימי הקטן-ביותר (במטרים) מבין קצוות-המחבר של מוצר —
"צוואר-הבקבוק" של הזרימה, שאליו מתכווצת אבידת-הלחץ. במקור מתודה-פרטית
`_minBoreOf` שקוראת לשני שכנים; שניהם הופכו כאן לשקעי-פרמטר (חוק-3).

## חתימה
```dart
double? minBoreOf<P, E>(
  P p, {
  required List<E>? Function(P) endsOf,
  required double? Function(E) boreOf,
})
```

## קלט
| שם | טיפוס | משמעות | עוגן-מקור |
|----|-------|--------|-----------|
| `p` | `P` | המוצר (במקור `LipskeyCatalogProduct`, בעל `.sku`) | pressure_drop.dart:104 |
| `endsOf` | `List<E>? Function(P)` | שקע: `p` → רשימת-הקצוות; **null כשאין spec למוצר** — מגלם את `kVerifiedSpecs[p.sku]?.ends` | pressure_drop.dart:105-108 |
| `boreOf` | `double? Function(E)` | שקע: קצה → קוטר-פנים במטרים, או null כשאינו ניתן-לפענוח — מגלם את `_boreMeters(e)` | pressure_drop.dart:109 |

## פלט
`double?` — הקוטר הקטן-ביותר (מטרים) מבין הקצוות בעלי-הקוטר.
מחזיר `null` בשני מקרים (שניהם מהמקור):
1. `endsOf(p) == null` (אין spec למוצר) — early return, מקור:106.
2. אף קצה אינו בעל קוטר ניתן-לפענוח (`min` נשאר null) — מקור:113.

## התנהגות (מהמקור, ביט-אחר-ביט)
- מביא `ends = endsOf(p)`; אם null ⇒ מחזיר null (מקור:105-106).
- עובר על הקצוות; מדלג על קצה שקוטרו null (`continue`, מקור:110).
- שומר את המינימום הרץ: `if (min == null || b < min) min = b` (מקור:111).
- כולל ערכים שליליים ואפס — אין סינון-סף; ההשוואה `<` בלבד.

## דוגמאות מספריות (מקריאת-הקוד)
נגזרות עם `boreOf` = הפונקציה מ-`bore_meters.dart` על מפת-BSP האמיתית
