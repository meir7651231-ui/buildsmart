# חוזה · אטום-חוט "frictionFactor" (מקדם-חיכוך Darcy מודע-ריינולדס)

**תפקיד:** מחזיר את מקדם-החיכוך של Darcy למים בצינור חלק, לפי מספר-ריינולדס.
חוט טהור (חוק-1): קלט מספרי + שקע-פונקציה, פלט מספרי. אפס import, אפס תלות-אטום.

**מוצא (עוגני-שורה, דיבר 11):** `buildsmart/app_flutter/lib/logic/pressure_drop.dart`
- `_frictionFactor(double reynolds)` — שורות **317–323** (גוף בן 3 ענפים).
- הקריאה-לשכן `_pow025(reynolds)` — שורה **322**, שמקורו `pressure_drop.dart:325` — **הפכה לשקע-מוזרק** (חוק-3).

## חתימה
```dart
double frictionFactor(double reynolds, {required double Function(double) pow025})
```

## שקע מוזרק (חוק-3, מתועד)
- **pow025(x) ⇒ x^0.25** — מחשב את השורש-הרביעי של `reynolds`. במקור זהו `_pow025`
  (‏`sqrt(sqrt(x))` דרך Newton-5-איטרציות, **לא** `pow()` של dart — ולכן **לא מדויק
  מתמטית** לערכים גדולים; חוק-4 מחייב לשמר בדיוק את חוסר-הדיוק הזה). האטום אינו יודע
  את המימוש — הקופסה מחווטת אותו. נקרא **אך ורק** בענף Re ≥ 2300.

## התנהגות (verbatim מהמקור, שורות 318–322)
1. `reynolds < 100` ⇒ מחזיר `0.64` (טפטוף איטי — תקרה נגד התפוצצות). כולל 0 ושליליים.
2. `100 ≤ reynolds < 2300` ⇒ מחזיר `64.0 / reynolds` (זרימה לאמינרית).
3. `reynolds ≥ 2300` ⇒ מחזיר `0.316 / pow025(reynolds)` (Blasius, צינור-חלק טורבולנטי).

**אי-רציפות מכוונת ב-Re=2300** (נשמרת מהמקור): בדיוק מתחת לסף הפלט ≈0.02783 (לאמינרי),
ומ-2300 ומעלה הוא קופץ ל-≈0.04257 (Blasius עם pow025 הלא-מדויק). לא מחליקים (חוק-4).

## דוגמאות מחייבות (מספריות — חושבו מהמקור-החי, ‏pow025 = _pow025 המקורי)
| קלט `reynolds` | ענף | פלט צפוי |
|---|---|---|
| `50.0`   | 1 (‏<100) | `0.64` |
| `0.0`    | 1 (עדשת-קצה) | `0.64` |
| `-5.0`   | 1 (שלילי — עדשת-קצה) | `0.64` |
| `99.999` | 1 | `0.64` |
| `100.0`  | 2 (סף — `100<100` שקר) | `0.64` (‏64/100) |
| `1000.0` | 2 | `0.064` |
| `2000.0` | 2 | `0.032` |
| `2299.999` | 2 | `0.02782609905482568` |
| `2300.0` | 3 (סף Blasius) | `0.04257426326393983` |
| `5000.0` | 3 | `0.03186200857405711` |
| `10000.0`| 3 | `0.023748791125411388` |
| `100000.0`| 3 | `0.007329733454851802` |

הערך בענף-3 = `0.316 / pow025(reynolds)`, כאשר לדוגמה `pow025(10000)=13.305940430032145`.

## עדשה-עוינת (CURRICULUM #6)
- `0` ו-`-5` (‏<100) ⇒ `0.64` — המקור **לא** קורא ל-pow025 בענף-1, כך שאין חלוקה-באפס
  ולא נוגעים בשלילי. האטום מתנהג זהה (הבדיקה מוודאת ש-pow025 **לא** נקרא בענפים 1–2).
- הסף `100` שייך לענף-2 (`<100` שקר) — במקרה נותן גם הוא `0.64` (64/100), רציף.
- הסף `2300` שייך לענף-3 — נקודת אי-הרציפות; מאומתת בשתי הדוגמאות 2299.999 מול 2300.0.
