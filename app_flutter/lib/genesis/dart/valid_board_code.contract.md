## פלט / התנהגות (עוגני-שורה)
- `input_validators.dart:60` — `digits = input.replaceAll(RegExp(r'[\s-]'), '')`:
  מסירים **אך ורק** תווי-רווח (`\s` = רווח/טאב/newline/…) ומקף (`-`). כל תו אחר
  (אות · נקודה · סוגריים · `+`) **נשאר** במחרוזת.
- `input_validators.dart:61` — `return RegExp(r'^\d{4}$').hasMatch(digits)`:
  true אם ורק אם `digits` הוא **בדיוק 4 ספרות-ASCII** (`\d` = 0-9, בלי דגל-יוניקוד
  ⇒ ספרות ערביות-הודיות אינן נספרות). פחות/יותר מ-4, או כל תו לא-ספרתי ⇒ false.

## עדשה-עוינת (CURRICULUM #6)
המקור מסיר `[\s-]` בלבד — **לא** `\D` (הבחנה מכוונת מ-`waMeDigits`/`normalizePhone`
שבאותו קובץ מסירים `\D`). לכן סוגריים/`+`/נקודה אינם מנוקים, וקלט-קצה כמו `"(12)34"`
נשאר-כפי-שהוא ⇒ false. הריק (`""`) ⇒ false, לא חריגה. אלה מאומתים כאן ביט-אחר-ביט.
