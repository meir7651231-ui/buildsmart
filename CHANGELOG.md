## Versioning proposal (SemVer) · הצעת גרסאות

> **Proposal only — no tag has been created.** · **הצעה בלבד — לא נוצרה תגית.**

- **Today:** the app version in `app_flutter/pubspec.yaml` is `1.5.2+14`; the in-app build label (`v7.02`) is a separate internal counter generated by `scripts/gen_version.sh` from `app_flutter/knowledge/STATUS.md`.
- **Proposal:** use the pubspec version as the release version and tag it `vMAJOR.MINOR.PATCH`, starting with `v1.5.2` on the commit that ships to the stores.
  - **MAJOR** — a change that breaks stored data or the backend contract (Firestore schema, Cloud Functions API).
  - **MINOR** — a new user-facing feature.
  - **PATCH** — fixes only.
  - The `+N` build number stays the store build code and only goes up.
- Each tag gets its own section below, moved out of **Unreleased**.
